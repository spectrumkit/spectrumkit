# Coole Modus

## Aktivierung des coolen Modus 🌈🌈🌈

Sie können den coolen Modus über das `coolMode`-Prop im `RainbowKitProvider` aktivieren.

```tsx
import { RainbowKitProvider } from '@spectrumkit/spectrumkit';

const App = () => (
  <RainbowKitProvider coolMode {...etc}>
    {/* Your App */}
  </RainbowKitProvider>
);
```

### Aber was ist das?

Emoji-Explosionen, wenn ein Wallet aus der Wallet-Liste ausgewählt wird 🌈🌈🌈. Es verwendet das Symbol des ausgewählten Wallets.
