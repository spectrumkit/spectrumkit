# Modo Cool

## Activar modo cool 🌈🌈🌈

Puedes activar el modo cool a través de la propiedad `coolMode` en el `RainbowKitProvider`.

```tsx
import { RainbowKitProvider } from '@spectrumkit/spectrumkit';

const App = () => (
  <RainbowKitProvider coolMode {...etc}>
    {/* Your App */}
  </RainbowKitProvider>
);
```

### ¿Pero qué es?

Explosiones de emojis cuando se selecciona una billetera de la lista de billeteras 🌈🌈🌈. Utiliza el icono de la billetera que selecciones.
