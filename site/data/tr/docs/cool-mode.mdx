# Havalı Mod

## Havalı modu etkinleştirme 🌈🌈🌈

Havalı modu `RainbowKitProvider`'da `coolMode` özelliği ile etkinleştirebilirsiniz.

```tsx
import { RainbowKitProvider } from '@spectrumkit/spectrumkit';

const App = () => (
  <RainbowKitProvider coolMode {...etc}>
    {/* Your App */}
  </RainbowKitProvider>
);
```

### Ama nedir bu?

Cüzdan listesinden bir cüzdan seçildiğinde emoji patlamaları 🌈🌈🌈. Seçtiğiniz cüzdanın simgesini kullanır.
