# Modo Legal

## Habilitando o modo legal 🌈🌈🌈

Você pode habilitar o modo legal via a prop `coolMode` no `RainbowKitProvider`.

```tsx
import { RainbowKitProvider } from '@spectrumkit/spectrumkit';

const App = () => (
  <RainbowKitProvider coolMode {...etc}>
    {/* Your App */}
  </RainbowKitProvider>
);
```

### Mas o que é isso?

Explosões de emoji quando uma carteira é selecionada da lista de carteiras 🌈🌈🌈. Usa o ícone da carteira que você selecionar.
