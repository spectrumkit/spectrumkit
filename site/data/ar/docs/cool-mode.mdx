# الوضع الرائع

## تمكين الوضع الرائع 🌈🌈🌈

يمكنك تمكين الوضع الرائع عبر الخاصية `coolMode` في `RainbowKitProvider`.

```tsx
import { RainbowKitProvider } from '@spectrumkit/spectrumkit';

const App = () => (
  <RainbowKitProvider coolMode {...etc}>
    {/* Your App */}
  </RainbowKitProvider>
);
```

### لكن ما هو؟

انفجار الرموز التعبيرية عند اختيار محفظة من قائمة المحافظ 🌈🌈🌈. يتم استخدام أيقونة المحفظة التي تختارها.
