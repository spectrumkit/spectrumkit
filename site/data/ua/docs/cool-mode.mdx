# Режим Cool

## Увімкнення режиму Cool 🌈🌈🌈

Ви можете увімкнути режим Cool через властивість `coolMode` в `RainbowKitProvider`.

```tsx
import { RainbowKitProvider } from '@spectrumkit/spectrumkit';

const App = () => (
  <RainbowKitProvider coolMode {...etc}>
    {/* Your App */}
  </RainbowKitProvider>
);
```

### Але що це таке?

Експлозії емодзі, коли вибирається гаманець зі списку гаманців 🌈🌈🌈. Використовується іконка обраного вами гаманця.

#### Демо

Натисніть кнопки нижче, щоб побачити, що робить режим Cool.
