# โหมดเท่ห์

## เปิดใช้งานโหมดเท่ห์ 🌈🌈🌈

คุณสามารถเปิดใช้งานโหมดเท่ห์ผ่านทาง prop `coolMode` บน `RainbowKitProvider`.

```tsx
import { RainbowKitProvider } from '@spectrumkit/spectrumkit';

const App = () => (
  <RainbowKitProvider coolMode {...etc}>
    {/* Your App */}
  </RainbowKitProvider>
);
```

### แต่มันคืออะไร?

การระเบิดของอีโมจิเมื่อเลือกกระเป๋าเงินจากรายการกระเป๋าเงิน 🌈🌈🌈. ใช้สัญลักษณ์ของกระเป๋าเงินที่คุณเลือก.

#### เดโม
