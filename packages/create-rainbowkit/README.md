# 🌈🚀 create-rainbowkit

Scaffold a new RainbowKit project.

```bash
npm init @spectrumkit/spectrumkit@latest
# or
pnpm create @spectrumkit/spectrumkit@latest
# or
yarn create @spectrumkit/spectrumkit
```
